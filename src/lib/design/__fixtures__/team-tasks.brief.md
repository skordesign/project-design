Task tracker.

## Overview

A web app where small teams create projects, add tasks, assign them and get an email when a task is assigned to them.

**Goals**
- Create, assign and complete tasks
- Email the assignee on assignment

**Non-goals**
- Mobile apps
- Real-time collaboration

**Architecture style:** clean — Clean Architecture: entities → use cases → interface adapters → frameworks; dependencies point inward only.

The API follows Clean Architecture. Side effects (email) happen in a worker fed by events.

**Repository:** monorepo, npm

## Decisions

### [adr_events] Send email from a worker, not from the request — accepted · 2026-10-01

**Context.** Email providers are slow and fail transiently.

**Decision.** The API publishes task.assigned; the notifier worker sends the email.

**Consequences.** Emails are eventually consistent; the API stays fast.
